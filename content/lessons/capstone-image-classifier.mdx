<h2 id="intuition">The month's arc, in one training run</h2>

Trace the path from the first lesson to here: `torch.Tensor` as `Value` generalized to N-
dimensional arrays → shape/dtype/device → broadcasting → tensor-level autograd → why GPUs
matter → `nn.Module`'s automatic parameter registration → `nn.Linear` and activations →
cross-entropy for classification → SGD and Adam → a complete training script →
`Dataset`/`DataLoader` → train/validation splits and overfitting → weight decay, dropout, and
batch normalization → convolution → pooling → a full CNN architecture → learning rate schedules
and early stopping. This lesson's single code cell uses essentially all of it: a real
convolutional network, trained end to end with Adam and a cosine learning rate schedule, on a
genuine (if small and synthetic) image classification task — distinguishing images containing a
vertical line from images containing a horizontal line.

<h2 id="math">The architecture</h2>

<MathBlock tex="\text{image}\ (8,8) \xrightarrow{\text{conv}\ 4\times3\times3} (4,6,6) \xrightarrow{\text{ReLU}} (4,6,6) \xrightarrow{\text{maxpool}\ 2\times2} (4,3,3) \xrightarrow{\text{flatten}} (36,) \xrightarrow{\text{linear}} (2,)" />

Four 3×3 kernels detect local patterns; ReLU introduces nonlinearity; 2×2 max pooling shrinks
and adds positional tolerance; flatten bridges to a final linear layer producing 2 class
logits, trained with cross-entropy loss.

```python
# reference only -- torch isn't available in this browser sandbox
import torch.nn as nn, torch.optim as optim

class TinyCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv = nn.Conv2d(1, 4, kernel_size=3)
        self.pool = nn.MaxPool2d(2, 2)
        self.fc = nn.Linear(4 * 3 * 3, 2)
    def forward(self, x):
        x = self.pool(torch.relu(self.conv(x)))
        return self.fc(x.flatten(start_dim=1))

model = TinyCNN()
loss_fn = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.05)
scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=40)
for epoch in range(40):
    for x_batch, y_batch in train_loader:
        logits = model(x_batch)
        loss = loss_fn(logits, y_batch)
        optimizer.zero_grad(); loss.backward(); optimizer.step()
    scheduler.step()
```

<Callout kind="tip" title="Everything here scales up, unchanged in kind, to a real classifier">
  A production image classifier (ResNet, or any modern CNN) differs from this capstone in
  degree, not in kind: more conv layers, more channels, larger images, batch normalization
  between layers, dropout before the final classifier, tens of thousands of real training
  images instead of 24 synthetic ones — but every one of those pieces was verified from scratch
  somewhere in this month. Nothing conceptually new remains between this capstone and a real
  production model; the rest is scale and engineering.
</Callout>

## Month 4 summary

This month bridged Month 3's hand-built autograd engine to the real framework professionals
use: PyTorch's tensor, autograd, and `nn.Module` APIs (week one and two) generalize the exact
concepts already built by hand, verified throughout via NumPy since this platform's Python
sandbox doesn't include PyTorch itself; datasets, splits, and three regularization techniques
(week three) address the practical problem of learning from limited data without memorizing
it; and convolution, pooling, and a complete CNN architecture (week four) culminate in this
capstone — a real, trainable image classifier, built and verified entirely from first
principles. Month 5 turns to probability, statistics, and the beginnings of natural language
processing — the mathematical foundation behind loss functions, evaluation metrics, and
language modeling still to come.
