<h2 id="intuition">The name for "several layers stacked," precisely</h2>

A **Multi-Layer Perceptron (MLP)** — despite the name, built from modern neurons with real
activation functions, not literal 1958-style perceptrons — is exactly what its name says: an
input layer, one or more **hidden layers**, and an output layer, each one a `z = Wx + b`
layer (week four's first lesson) followed by an activation function (week three). This is the
architecture this month's capstone project builds.

<h2 id="math">Architecture notation</h2>

An MLP's architecture is often summarized as a list of layer sizes, e.g. `[4, 8, 8, 3]` meaning:
4 input features → hidden layer of 8 neurons → hidden layer of 8 neurons → output layer of 3
neurons (e.g., 3-class classification). Each consecutive pair of numbers defines one weight
matrix's shape:

<MathBlock tex="\text{layer } i \text{: } W_i \in \mathbb{R}^{(\text{sizes}[i+1])\times(\text{sizes}[i])}, \qquad b_i \in \mathbb{R}^{\text{sizes}[i+1]}" />

For `[4, 8, 8, 3]`: `W_1` is `(8, 4)`, `W_2` is `(8, 8)`, `W_3` is `(3, 8)` — three weight
matrices for three layers of connections between four "layers" of neurons (counting the input).

<Callout kind="tip" title="A detail worth noticing: He initialization">
  Weights are initialized as random values scaled by `sqrt(2/n_in)`, not just plain random
  numbers — this is **He initialization**, chosen specifically to keep signal variance roughly
  stable as it passes through ReLU layers at the start of training, before any learning has
  happened. Poor initialization is a real, common source of training failure; this is a
  preview of a topic Month 3 and 4 return to in more depth.
</Callout>

## Summary

An MLP's architecture is a list of layer sizes; each consecutive pair defines one weight
matrix's shape `(n_out, n_in)`. The forward pass applies each layer's `z = Wx + b` followed by
an activation — ReLU for hidden layers, softmax for a multi-class output layer, matching last
week's guidance. This class is the direct scaffold for this month's capstone.
