<h2 id="intuition">Every lesson this month, assembled</h2>

This is month one's capstone lesson: a working matrix calculator library, built from exactly
the pieces the last three weeks covered — vectors, matrix operations, matrix multiplication,
inverses and solving systems — wrapped in tests, ready to package and publish. Nothing here
is new math; this is entirely about assembly, structure, and the software-engineering habits
from Week 2.

<Callout kind="tip" title="Public API vs. internals">
  A well-structured small library has a clear boundary: a few public functions users are meant
  to call (`add`, `multiply`, `solve`, ...), and internal helpers they're not meant to depend on
  directly. This isn't about hiding code — it's about giving yourself freedom to change internal
  details later without breaking anyone (including future-you) who depends on the public API.
</Callout>

<h2 id="python">A minimal, tested matrix calculator</h2>

<CodeCell
