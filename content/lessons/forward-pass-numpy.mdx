<h2 id="intuition">One more vectorization step: many examples, not just many neurons</h2>

Last lesson's MLP processes one input vector at a time. Real training and inference process
**batches** — many examples at once — for the same reason Month 1 pushed vectorization over
loops: a batched matrix operation is dramatically faster than looping over examples one by one,
and every deep learning framework is built around batched computation as the default, not the
exception.

<h2 id="math">Batching: stack examples as rows, adjust the multiplication order</h2>

Instead of one input vector `x` of shape `(n,)`, a batch is a matrix `X` of shape
`(batch_size, n)` — one row per example. The layer computation adapts:

<MathBlock tex="Z = XW^{\top} + b \qquad X \in \mathbb{R}^{(\text{batch}\times n)},\; W \in \mathbb{R}^{(m\times n)},\; Z \in \mathbb{R}^{(\text{batch}\times m)}" />

Notice `W` is now **transposed** compared to the single-example version (`W @ x` becomes
`X @ W.T`) — this is purely about making the shapes line up correctly for batched matrix
multiplication (`(batch, n) @ (n, m) = (batch, m)`), not a conceptual change; `b` broadcasts
across the batch dimension exactly as Month 1's broadcasting lesson covered.

<h2 id="python">Batched forward pass, and the speedup it buys</h2>

<CodeCell
  code={"import numpy as np\nimport time\n\ndef relu(z):\n    return np.maximum(0, z)\n\ndef softmax_batch(z):\n    exp_z = np.exp(z - z.max(axis=-1, keepdims=True))\n    return exp_z / exp_z.sum(axis=-1, keepdims=True)\n\nclass BatchedMLP:\n    def __init__(self, layer_sizes, seed=0):\n        rng = np.random.RandomState(seed)\n        self.weights = [rng.randn(layer_sizes[i+1], layer_sizes[i]) * np.sqrt(2 / layer_sizes[i])\n                         for i in range(len(layer_sizes) - 1)]\n        self.biases = [np.zeros(layer_sizes[i+1]) for i in range(len(layer_sizes) - 1)]\n\n    def forward_single(self, x):\n        for i, (W, b) in enumerate(zip(self.weights, self.biases)):\n            z = W @ x + b\n            x = softmax_batch(z) if i == len(self.weights) - 1 else relu(z)\n        return x\n\n    def forward_batch(self, X):\n        for i, (W, b) in enumerate(zip(self.weights, self.biases)):\n            Z = X @ W.T + b\n            X = softmax_batch(Z) if i == len(self.weights) - 1 else relu(Z)\n        return X\n\nmodel = BatchedMLP([20, 64, 64, 10])\nbatch_size = 500\nX = np.random.randn(batch_size, 20)\n\n# --- looped: one example at a time ---\nstart = time.perf_counter()\nlooped_results = np.array([model.forward_single(X[i]) for i in range(batch_size)])\nlooped_time = time.perf_counter() - start\n\n# --- batched: all examples at once ---\nstart = time.perf_counter()\nbatched_results = model.forward_batch(X)\nbatched_time = time.perf_counter() - start\n\nprint(\"looped output shape: \", looped_results.shape)\nprint(\"batched output shape:\", batched_results.shape)\nprint(\"results match?\", np.allclose(looped_results, batched_results, atol=1e-6))\nprint()\nprint(f\"looped time:  {looped_time*1000:.2f} ms\")\nprint(f\"batched time: {batched_time*1000:.2f} ms\")\nprint(f\"speedup: {looped_time / max(batched_time, 1e-9):.1f}x\")"}
  output={"looped output shape:  (500, 10)\nbatched output shape: (500, 10)\nresults match? True\n\nlooped time:  10.12 ms\nbatched time: 3.18 ms\nspeedup: 3.2x"}

## Summary

Batching stacks multiple examples as rows of a matrix `X` (shape `(batch, n)`), requiring the
weight matrix to be transposed (`X @ W.T`) so the shapes align per Month 1's matrix
multiplication rule — otherwise identical to the single-example forward pass, just computing
many examples in one operation instead of looping. This delivers the same kind of speedup
Month 1's vectorization lessons demonstrated, and it's how every real training pipeline
processes data.
