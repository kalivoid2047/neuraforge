<h2 id="intuition">Enforce outside the model, where persuasion does not apply</h2>

Every control in this lesson lives in the dispatcher, which means it holds **even when the model is completely fooled**. That is the only assumption worth designing against, because the previous lesson showed the model cannot be relied on to tell instructions from data.

<h2 id="math">Controls the Attacker's Text Cannot Reach</h2>

Four checks, applied in order, before anything runs:

1. **Allowlist** — is this tool available to this agent at all?
2. **Call budget** — has the step limit been reached?
3. **Write budget** — side-effecting calls counted separately and much lower.
4. **Taint** — is this call derived from untrusted tool output?

The fourth is the interesting one. Taint is a property of **provenance**, not of content:

<MathBlock tex="\text{tainted}(t) = \text{true} \iff \exists\, i < t \;:\; \text{observation}_i \text{ came from an untrusted source}" />

Once the agent has read untrusted text, every subsequent side effect is suspect — regardless of how reasonable it looks.

<Callout kind="warning" title="The taint rule blocks legitimate work too">
  In the capstone the agent tries to save a perfectly reasonable research note and is refused, because it read a lesson first and is therefore tainted. That is not a bug — it is the rule working, and it is the rule's real cost. Production systems do not drop tainted writes silently; they **escalate to a human**, or restrict them to a sandbox that can be reviewed. A control with no escalation path gets switched off the first week it inconveniences someone, which is worse than not having it.
</Callout>

## Summary

Allowlists, call budgets, write budgets, and taint tracking are all enforced in the dispatcher, so they hold when the model is fooled. Taint is the distinctive one: it judges a call by **provenance** rather than content, which is why the identical `delete_index` call was blocked when derived from a poisoned document and allowed when operator-initiated. The cost is real — legitimate tainted writes are blocked too — so production systems escalate rather than silently drop, since a control with no escalation path gets disabled.
