<h2 id="intuition">Depth is worthless without nonlinearity — provably, not just empirically</h2>

Week two closed on "stacking neurons into layers escapes the linear separability limit." That's
only true if something *nonlinear* happens between the layers. This lesson proves — not just
asserts — that stacking purely linear layers, with no nonlinearity between them, is exactly
equivalent to a single linear layer. No amount of depth without nonlinearity buys you anything.

<h2 id="math">The collapse proof</h2>

A linear layer computes `y = Wx + b`. Stack two of them, feeding the first's output into the
second:

<MathBlock tex="y = W_2(W_1x + b_1) + b_2 = (W_2W_1)x + (W_2b_1 + b_2)" />

Let `W' = W_2W_1` and `b' = W_2b_1 + b_2` — both are just fixed matrices/vectors, computable
once you know `W_1, W_2, b_1, b_2`. The whole two-layer computation reduces to:

<MathBlock tex="y = W'x + b'" />

— a *single* linear layer. This generalizes to any number of stacked linear layers: they always
collapse to one. An **activation function** applied between layers (`y = W_2\,\sigma(W_1x + b_1) + b_2`)
breaks this collapse, because `σ` (if nonlinear) cannot be absorbed into a single matrix
multiplication the way pure linear composition can.

<h2 id="python">Verifying the collapse numerically</h2>

  This is precisely why every real neural network applies a nonlinear activation between
  layers — without one, no amount of added depth increases what the network can represent
  beyond a single linear transformation. The next three lessons cover which nonlinear functions
  are actually used, and why the choice matters.

## Summary

Composing any number of purely linear layers algebraically collapses to a single linear
layer — `W_2(W_1x + b_1) + b_2` simplifies to `W'x + b'` for a single effective weight matrix
and bias, and this holds for arbitrarily many stacked linear layers. A nonlinear activation
function between layers is what prevents this collapse, and is therefore what makes depth
actually buy a network additional representational power.
