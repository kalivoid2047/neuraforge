<h2 id="intuition">A model you download is not magic — it is a config and a tensor dump</h2>

"Loading a pretrained model" sounds like it involves something special. It does not. A
checkpoint is a directory containing a JSON file describing the architecture, a binary file of
weights, and the tokenizer's vocabulary. Everything in it maps onto structures already built in
Months 6–8. Knowing that makes the ecosystem far less opaque — and makes it obvious why certain
things (like checkpoint file format) are security-relevant.

<h2 id="math">A checkpoint is files</h2>

```python
# reference only -- transformers isn't available in this browser sandbox
from transformers import AutoModelForCausalLM, AutoTokenizer

model = AutoModelForCausalLM.from_pretrained("meta-llama/Llama-2-7b-hf")
tok   = AutoTokenizer.from_pretrained("meta-llama/Llama-2-7b-hf")

# `Auto*` reads config.json, sees "architectures": ["LlamaForCausalLM"],
# and instantiates that class -- then loads the tensors into it by name.
```

The `Auto` classes do exactly one clever thing: read `config.json`, look up which model class the
architecture string names, construct it, and populate its parameters from the weight file by
matching names. There is no inference of structure — the config states it.

<Callout kind="warning" title="A .bin checkpoint can execute code when you load it">
  PyTorch's original `.bin` format is Python **pickle**, and unpickling is not a passive
  operation — it can construct arbitrary objects and run arbitrary code. Downloading a `.bin`
  from an untrusted account and loading it is equivalent to running that account's script on your
  machine.

  **safetensors** exists to eliminate this: it is a flat header-plus-tensors format with no
  execution path at all. Prefer it for anything you did not produce yourself, and treat a
  repository that offers *only* `.bin` as a reason for caution.
</Callout>

## Summary

A checkpoint is a config describing the architecture, a weight file, and a tokenizer — every part
mapping onto structures from Months 6–8. The `Auto` classes simply read the architecture name
from `config.json` and populate the matching class by tensor name. The config fully determines
the parameter count, verified by reconstructing Llama-2-7B's 6.738B from its published
hyperparameters. Checkpoint format is a genuine security boundary: `.bin` is pickle and executes
code on load, while safetensors cannot. The next lesson examines what full fine-tuning actually
changes in those weights.
