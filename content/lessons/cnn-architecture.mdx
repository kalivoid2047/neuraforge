<h2 id="intuition">A CNN is just this month's pieces, in a specific order</h2>

A typical image classifier's architecture is a straightforward recipe: alternate convolution
(detect local patterns) and pooling (shrink and add positional tolerance) a few times, then
**flatten** the resulting feature map into a flat vector and feed it through ordinary
`nn.Linear` layers (exactly like every non-image network this month) to produce final class
logits. Nothing new is being introduced here — this lesson is entirely about *composition*:
chaining the pieces already built (convolution, pooling, linear, activation, softmax/cross-
entropy) into one working pipeline.

<h2 id="math">Tracking shapes through the network</h2>

<MathBlock tex="\text{image}\ (1,28,28) \xrightarrow{\text{conv}} (8,26,26) \xrightarrow{\text{pool}} (8,13,13) \xrightarrow{\text{flatten}} (1352,) \xrightarrow{\text{linear}} (10,)" />

Each arrow is a layer; the numbers in parentheses are the shape flowing through it. **Flatten**
does no computation at all — it just reinterprets a multi-dimensional feature map as one long
vector (a `reshape`, from the very first Month 4 lesson), because `nn.Linear` only knows how to
operate on flat vectors, not 3D feature maps.

```python
# reference only -- torch isn't available in this browser sandbox
import torch.nn as nn

class SimpleCNN(nn.Module):
    def __init__(self, n_classes):
        super().__init__()
        self.conv = nn.Conv2d(1, 8, kernel_size=3)     # (1,28,28) -> (8,26,26)
        self.pool = nn.MaxPool2d(2, 2)                 # (8,26,26) -> (8,13,13)
        self.fc = nn.Linear(8 * 13 * 13, n_classes)    # flatten -> linear -> logits

    def forward(self, x):
        x = self.pool(torch.relu(self.conv(x)))
        x = x.flatten(start_dim=1)   # keep the batch dimension, flatten the rest
        return self.fc(x)
```

<Callout kind="tip" title="Multiple kernels = multiple 'channels' of feature maps">
  A real conv layer almost never uses just one kernel — `nn.Conv2d(in_channels, out_channels,
  ...)`'s `out_channels` is exactly how many independent kernels it learns, each looking for a
  *different* pattern (one might respond to vertical edges, another to a particular texture).
  Each kernel produces its own feature map, and all of them get pooled and flattened together —
  exactly what the two kernels above demonstrate, doubling the channel count from 1 to 2.
</Callout>

## Summary

A CNN architecture is a composition, not a new concept: convolution and ReLU detect and
activate local patterns, pooling shrinks the resulting feature maps, flatten bridges the
multi-dimensional feature maps into a flat vector, and a final linear layer (exactly like every
non-image network this month) produces class logits — verified end to end above with two
kernels producing two feature maps, pooled, flattened, and classified. The next lesson covers
learning rate schedules and early stopping — two practical training techniques the capstone
will use. The lesson after that assembles everything from this entire month into the Image
Classifier capstone.
