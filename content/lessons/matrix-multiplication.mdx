<h2 id="intuition">Every dot product you learned last week, organized into a grid</h2>

Matrix multiplication looks intimidating written out in full, but it's built entirely from one
operation you already know cold: the dot product. `C = A @ B` computes every entry of `C` as
the dot product of one row of `A` with one column of `B`. That's the whole mechanism — the
apparent complexity is just doing this many times, once per output position.

<Callout kind="tip" title="The one-sentence rule">
  Entry `C[i][j]` is the dot product of row `i` of `A` and column `j` of `B`. Nothing else is
  happening.
</Callout>

<h2 id="math">The shape rule</h2>

For `A @ B` to be valid, `A`'s number of *columns* must equal `B`'s number of *rows* — the
"inner" dimensions must match:

<MathBlock tex="A_{(m \times n)} \; @ \; B_{(n \times p)} \;=\; C_{(m \times p)}" />

The `n`'s must match (and disappear from the result); the output takes `A`'s row count and `B`'s
column count. This single rule is worth memorizing cold — you'll use it to debug shape errors
constantly for the rest of this course, including in every attention computation come Month 7.

<Callout kind="danger" title="Matrix multiplication is NOT commutative">
  `A @ B ≠ B @ A` in general — order matters, unlike ordinary number multiplication. This isn't
  a rare edge case; it's the normal situation, and it's a common source of bugs when translating
  math notation (where order is written carefully and deliberately) into code. When you see
  `AB` in a formula, the order is never arbitrary.
</Callout>

## Summary

Matrix multiplication computes each output entry as a dot product of a row from the left matrix
and a column from the right matrix, requiring the left matrix's column count to match the right
matrix's row count — `(m,n) @ (n,p) = (m,p)`. Order matters: `A @ B` and `B @ A` are generally
different (and often one isn't even valid), unlike ordinary number multiplication. This single
operation, applied repeatedly, is the computational core of essentially every neural network
layer you'll build for the rest of this course.
