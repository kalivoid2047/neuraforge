<h2 id="intuition">Month 8: from a translation model to a general-purpose one</h2>

Month 7 built an encoder-decoder Transformer for translation: the encoder reads the source
sentence, the decoder generates the target while attending back to the encoder's output via
cross-attention. That split makes obvious sense when input and output are genuinely different
things (English in, French out).

GPT-style models throw the split away entirely. There is **one stack**, and the "input" and
"output" simply occupy different positions in **one sequence**. Translation becomes:
`English: the cat sat. French: le chat...` — a single token sequence where the model predicts
what comes next, exactly as in Month 6's language modeling. The task didn't change; the framing
did, and that reframing is what makes one architecture handle translation, summarization,
question answering, and code completion without any structural change per task.

<h2 id="math">Dropping the encoder</h2>

A decoder-only block is an encoder block plus causal masking (Month 7, lesson 7.1.5). What it
*drops* is the cross-attention sublayer — the part that attended to encoder output — because
there is no encoder to attend to. Per block, that removes:

<MathBlock tex="\underbrace{4d_{\text{model}}^2}_{W_Q,W_K,W_V,W_O} + \underbrace{2d_{\text{model}}}_{\text{its LayerNorm}}" />

Everything else survives unchanged: self-attention, the feed-forward network, LayerNorm,
residual connections — all exactly as Month 7 built them.

<Callout kind="tip" title="Causal masking is what makes one stack sufficient">
  Without causal masking, a single stack couldn't generate anything — every position would see
  the whole sequence including its own answer. Causal masking (7.1.5) is precisely what lets one
  stack read a prompt *and* generate a continuation: positions in the prompt attend only
  backward, and each generated token attends to everything before it and nothing after. The
  encoder-decoder split was one way to separate "reading" from "writing"; causal masking is a
  cheaper one.
</Callout>

## Summary

A decoder-only model replaces the encoder-decoder split with a single causally-masked stack, in
which prompt and completion are just different positions in one sequence — so translation,
summarization, and question answering all become ordinary next-token prediction with no
per-task structural change. Dropping cross-attention removes `4d² + 2d` parameters per block,
which on the configuration measured above accounted for 10.4% of the encoder-decoder model.
The next lesson contrasts this causal language modeling objective with BERT's masked one.
