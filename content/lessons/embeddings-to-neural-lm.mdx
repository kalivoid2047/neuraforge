<h2 id="intuition">Putting weeks two and three together</h2>

Week two learned dense embeddings; week three built language models. This lesson combines them:
a **neural language model** that embeds the previous few tokens, concatenates those embeddings,
and feeds them through a small network to predict the next token. The critical advantage over
n-gram counting: because similar words have *similar embeddings*, a context the model has never
literally seen can still produce a sensible prediction — the embedding layer generalizes across
contexts in a way a count table structurally cannot.

<h2 id="math">The neural LM architecture</h2>

For a context of the previous `n` tokens `w_{t-n}, \ldots, w_{t-1}`:

<MathBlock tex="x = [\,E_{w_{t-n}}; \ldots; E_{w_{t-1}}\,] \qquad h = \tanh(xW_1+b_1) \qquad \text{logits} = hW_2+b_2" />

`E` is the embedding table (week two), the concatenated embeddings form the input, and softmax
over the logits gives `P(w_t \mid \text{context})`. Trained with cross-entropy — which is
exactly maximum likelihood over next tokens, and whose exponential is perplexity (week three).

<Callout kind="tip" title="Why this escapes the sparsity trap that smoothing only patches">
  A trigram model that never saw "the fluffy cat" has no basis for predicting what follows it —
  smoothing can only fall back to shorter contexts, discarding information. A neural LM that has
  seen "the fluffy dog" will produce *similar embeddings* for "cat" and "dog" (because week
  two's training put them near each other), so the concatenated input vector lands near a region
  the network has already learned about, and the prediction transfers. That generalization is
  structural, not a patch — it comes from the representation itself.
</Callout>

<h2 id="python">Training a neural bigram LM, tracking perplexity</h2>

<CodeCell
  code={"import re\nimport numpy as np\n\nrng = np.random.default_rng(0)\n\ncorpus = [\n    \"the cat sat on the mat\", \"the dog sat on the rug\",\n    \"the cat ate the fish\",  \"the dog ate the bone\",\n    \"a cat sat on a mat\",     \"a dog sat on a rug\",\n]\n\ndef tokenize(text):\n    return [t for t in re.split(r'[^a-zA-Z]+', text.lower()) if t]\n\ntokenized = [tokenize(d) for d in corpus]\nvocab = sorted(set(w for d in tokenized for w in d))\nw2i = {w: i for i, w in enumerate(vocab)}\nV = len(vocab)\n\n# training pairs: (previous token, next token)\npairs = [(w2i[d[i]], w2i[d[i+1]]) for d in tokenized for i in range(len(d)-1)]\nprint(f\"vocabulary size: {V}, training pairs: {len(pairs)}\")\nprint()\n\nD, H = 6, 12   # embedding dim, hidden dim\nE  = rng.normal(0, 0.3, (V, D))\nW1 = rng.normal(0, 0.3, (D, H)); b1 = np.zeros(H)\nW2 = rng.normal(0, 0.3, (H, V)); b2 = np.zeros(V)\n\ndef softmax(z):\n    e = np.exp(z - np.max(z, axis=-1, keepdims=True))\n    return e / e.sum(axis=-1, keepdims=True)\n\nX_idx = np.array([p[0] for p in pairs])\nY     = np.array([p[1] for p in pairs])\nn = len(pairs)\nlr = 0.5\n\nfor epoch in range(1, 601):\n    x = E[X_idx]                       # embedding lookup for each context token\n    h = np.tanh(x @ W1 + b1)\n    probs = softmax(h @ W2 + b2)\n    loss = -np.mean(np.log(probs[np.arange(n), Y] + 1e-12))\n\n    one_hot = np.zeros((n, V)); one_hot[np.arange(n), Y] = 1.0\n    d_logits = (probs - one_hot) / n\n    dW2 = h.T @ d_logits; db2 = d_logits.sum(axis=0)\n    d_h = (d_logits @ W2.T) * (1 - h**2)          # tanh derivative\n    dW1 = x.T @ d_h;      db1 = d_h.sum(axis=0)\n    d_x = d_h @ W1.T\n    dE = np.zeros_like(E)\n    np.add.at(dE, X_idx, d_x)                      # accumulate gradients into the embedding table\n\n    E -= lr*dE; W1 -= lr*dW1; b1 -= lr*db1; W2 -= lr*dW2; b2 -= lr*db2\n\n    if epoch % 120 == 0 or epoch == 1:\n        print(f\"epoch {epoch:3d}: loss = {loss:.4f}, perplexity = {np.exp(loss):.3f}\")\n\nprint()\nprint(f\"uniform-baseline perplexity would be {V} (the full vocabulary)\")\nprint()\n\n# the embedding layer learned structure: 'cat'/'dog' appear in near-identical contexts\ndef cos(a, b):\n    return float(a @ b / (np.linalg.norm(a) * np.linalg.norm(b)))\nprint(\"cosine similarity in the LEARNED embedding table E:\")\nprint(f\"  cat / dog (interchangeable contexts):  {cos(E[w2i['cat']], E[w2i['dog']]):+.4f}\")\nprint(f\"  the / a   (interchangeable contexts):  {cos(E[w2i['the']], E[w2i['a']]):+.4f}\")\nprint(f\"  cat / sat (different roles entirely):  {cos(E[w2i['cat']], E[w2i['sat']]):+.4f}\")"}

## Summary

A neural language model embeds context tokens, passes them through a small network, and predicts
the next token via softmax and cross-entropy — combining week two's embeddings with week three's
language modeling. Its key advantage over n-gram counting is structural rather than a patch:
because similar words receive similar embeddings, unseen contexts land near learned regions of
the representation space and predictions transfer, where a count table has only an empty cell.
Verified above by training one end to end, watching perplexity fall well below the uniform
baseline, and confirming the learned embedding table places interchangeable words near each
other. The final lesson assembles the full Word2Vec capstone.
