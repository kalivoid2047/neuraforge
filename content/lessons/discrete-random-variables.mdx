<h2 id="intuition">Naming outcomes with numbers</h2>

A **random variable** is simply a function that assigns a number to each outcome of a random
process — "number of heads in 10 coin flips," "whether an email is spam (1) or not (0)." Its
**probability mass function (PMF)** gives the probability of each possible value. Two
distributions come up constantly in machine learning: the **Bernoulli** (a single yes/no trial —
exactly the coin-flip-shaped random variable behind every binary classification label) and the
**Binomial** (the count of successes across many independent Bernoulli trials).

<h2 id="math">Bernoulli and Binomial</h2>

A Bernoulli random variable with success probability `p`:

<MathBlock tex="P(X=1) = p \qquad P(X=0) = 1-p" />

A Binomial random variable counts successes across `n` independent Bernoulli(`p`) trials:

<MathBlock tex="P(X=k) = \binom{n}{k} p^k (1-p)^{n-k} \qquad \text{where } \binom{n}{k} = \frac{n!}{k!(n-k)!}" />

`\binom{n}{k}` (read "n choose k") counts how many *different orderings* of `k` successes among
`n` trials exist — because any specific ordering with `k` successes has the same probability,
`p^k(1-p)^{n-k}`, but there are `\binom{n}{k}` such orderings to sum over.

<Callout kind="tip" title="Every binary classification label is a Bernoulli random variable">
  The true label in a binary classification problem (spam/not-spam, cat/not-cat) is exactly a
  Bernoulli random variable — and Month 4's cross-entropy loss, `-log(p_correct)`, is directly
  built from treating the network's predicted probability as an estimate of that Bernoulli's
  parameter `p`. This isn't a loose analogy; it's the literal statistical object cross-entropy
  is defined against, made precise in week two.
</Callout>

## Summary

A random variable assigns numbers to random outcomes; its PMF gives each value's probability.
Bernoulli models a single trial; Binomial counts successes across `n` independent Bernoulli
trials, with the binomial coefficient accounting for the number of orderings that produce the
same count — verified above against a million simulated 10-flip trials. Binary classification
labels are literally Bernoulli random variables, directly connecting to Month 4's cross-entropy
loss. The next lesson extends these ideas to continuous random variables and the Gaussian
distribution.
