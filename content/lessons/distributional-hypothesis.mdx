<h2 id="intuition">"You shall know a word by the company it keeps"</h2>

Last lesson showed dense embeddings *could* encode similarity — but where would the numbers come
from? Hand-labeling every word's meaning is hopeless at scale. The **distributional
hypothesis** provides the answer: **words appearing in similar contexts tend to have similar
meanings.** "cat" and "dog" both appear near "pet," "fur," "vet," and "feed"; "democracy"
appears near entirely different words. That observable statistical pattern — which requires no
human labeling whatsoever, just raw text — is enough to learn meaningful embeddings.

<h2 id="math">Co-occurrence as a representation</h2>

For a **context window** of size `w`, build a matrix `C` where:

<MathBlock tex="C_{ij} = \text{number of times word } j \text{ appears within } w \text{ positions of word } i" />

Each *row* of `C` is a vector describing which words tend to surround word `i`. Under the
distributional hypothesis, words with similar meanings should have similar rows — and that
similarity is directly measurable with the cosine similarity from Month 1, no labels required.

<Callout kind="tip" title="Co-occurrence rows are already embeddings -- just very large, sparse ones">
  A co-occurrence row is a genuine distributional representation of a word, and it works. But
  it's as long as the vocabulary (the same size problem as one-hot) and mostly zeros. Word2Vec
  and GloVe (the next lessons) both produce *dense, compact* versions of exactly this same
  distributional information — they differ in how they get there, not in the underlying signal
  they're extracting.
</Callout>

<h2 id="python">Building a co-occurrence matrix, with no meaning labels anywhere</h2>

window)\n        end = min(len(doc), pos + window + 1)\n        for ctx_pos in range(start, end):\n            if ctx_pos != pos:\n                C[i, word_to_index[doc[ctx_pos]]] += 1\n\nprint(f\"vocabulary size: {V}, co-occurrence matrix shape: {C.shape}\")\nprint()\n\ndef cosine_similarity(a, b):\n    denom = np.linalg.norm(a) * np.linalg.norm(b)\n    return float(a @ b / denom) if denom > 0 else 0.0\n\n# compare co-occurrence ROWS -- no labels, no supervision, purely from context statistics\ndef row(word):\n    return C[word_to_index[word]]\n\ncomparisons = [(\"cat\", \"dog\"), (\"cat\", \"democracy\"), (\"dog\", \"democracy\"), (\"cat\", \"pet\")]\nprint(\"cosine similarity between co-occurrence rows:\")\nfor a, b in comparisons:\n    print(f\"  sim({a:>9}, {b:>9}) = {cosine_similarity(row(a), row(b)):.4f}\")\n\nprint()\nprint(\"'cat' and 'dog' score high purely because they appear in near-identical contexts.\")\nprint(\"Nothing in this code was ever told what a cat or a dog IS -- only which words\")\nprint(\"happened to surround them in raw text. That's the distributional hypothesis at work.\")"}

## Summary

The distributional hypothesis — words in similar contexts have similar meanings — is what makes
learning embeddings from raw text possible at all, since context co-occurrence is a purely
statistical property requiring no human labeling. A co-occurrence matrix makes this concrete:
each row describes which words surround a given word, and rows for similar words score high on
cosine similarity, verified directly above with "cat" and "dog" scoring far higher than either
does against "democracy" — with nothing in the code ever told what those words mean. The next
lesson covers Word2Vec, which learns *dense* versions of this same distributional signal.
