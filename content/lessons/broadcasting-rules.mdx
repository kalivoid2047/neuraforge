<h2 id="intuition">Combining a batch of examples with one shared vector</h2>

A very common situation in deep learning: you have a *batch* of examples — say, 32 examples,
each with 10 features, shape `(32, 10)` — and you want to add the same 10-element bias vector,
shape `(10,)`, to every one of the 32 rows. Writing an explicit loop over all 32 rows would
work, but it's slow and verbose. **Broadcasting** is the rule set that lets `batch + bias` just
work directly, as if the smaller array were automatically "stretched" to match — without
actually copying any data.

<h2 id="math">The two broadcasting rules</h2>

Comparing two shapes from the **right**, dimension by dimension, two dimensions are compatible
if:

1. **They're equal**, or
2. **One of them is `1`** (or missing entirely, treated as `1`)

If every pair of dimensions satisfies one of these, the shapes are broadcast-compatible, and the
result takes the larger size in each dimension. If neither holds for some dimension, the
operation raises an error.

<MathBlock tex="(32,\ 10) \quad \text{and} \quad (10,) \;\rightarrow\; (32,\ 10)\ \text{and}\ (1,\ 10) \;\rightarrow\; \text{compatible, result shape } (32, 10)" />

/>

<Callout kind="tip" title="Broadcasting is why a bias term is just one line">
  Every linear layer computes `output = input @ weights + bias`, where `input` is a whole batch
  (shape `(batch_size, in_features)`) and `bias` is a single vector (shape `(out_features,)`).
  Broadcasting is precisely what makes `+ bias` correct and efficient here — the same bias
  values apply to every example in the batch, with no explicit loop and no wasted memory copying
  the bias vector 32 (or however many) times.
</Callout>

## Summary

Broadcasting lets operations combine arrays of different (but compatible) shapes without an
explicit loop or a real memory copy, by comparing shapes from the right and treating any
dimension of size `1` as stretchable to match the other array's size. This is exactly the
mechanism that makes adding a single bias vector across an entire batch of examples work as one
line of code. The next lesson returns to autograd, working through `requires_grad` and
`.backward()` end to end on tensors rather than the single scalars from Month 3.
