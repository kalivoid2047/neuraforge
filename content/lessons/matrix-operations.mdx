<h2 id="intuition">Familiar operations, one new one</h2>

Matrix addition and scalar multiplication work exactly like their vector counterparts from last
week, applied element-by-element — no new ideas needed there. The genuinely new operation this
lesson introduces is the **transpose**: flip a matrix over its diagonal, turning rows into
columns and columns into rows. It looks like a small bookkeeping operation; it turns out to be
essential to matrix multiplication (next lesson) and to nearly every neural network layer you'll
implement later in this course.

<h2 id="math">The transpose</h2>

<MathBlock tex="(A^{\top})_{ij} = A_{ji}" />

If `A` has shape `(m, n)`, then `A^T` has shape `(n, m)` — rows and columns swap counts. Entry
`(i, j)` of the transpose is entry `(j, i)` of the original.

<Callout kind="tip" title="A matrix equal to its own transpose is symmetric">
  If `A = A^T`, `A` is called **symmetric** — necessarily square (`m = n`), with entry `(i,j)`
  always equal to entry `(j,i)`. Symmetric matrices show up constantly: covariance matrices,
  similarity/distance matrices, and (much later) attention weight patterns in certain
  architectural variants.
</Callout>

<Callout kind="warning" title="Pitfall: addition requires identical shapes (not broadcastable-compatible)">
  Unlike some operations you met with broadcasting, matrix addition genuinely requires both
  matrices to have the *exact same shape* — there's no meaningful "add a (2,3) and a (3,2)."
  (Broadcasting between a matrix and a *vector*, like you saw in Week 1, is a different, valid
  case — this warning is specifically about adding two matrices of mismatched shape to each
  other.)
</Callout>

## Summary

Matrix addition and scalar multiplication work element-wise, requiring matching shapes for
addition. The transpose swaps rows and columns — a `(m, n)` matrix becomes `(n, m)` — and a
matrix equal to its own transpose is called symmetric. These operations, especially the
transpose, are the building blocks the next lesson's matrix multiplication depends on directly.
