<h2 id="intuition">When your reference directions don't interfere with each other</h2>

A set of vectors is **orthogonal** if every pair among them is perpendicular (dot product
zero). If they're also each unit length, the set is **orthonormal**. This might sound like a
narrow special case, but orthonormal sets are worth building toward deliberately: projecting
onto them is dramatically simpler than projecting onto an arbitrary basis, because each
direction can be handled completely independently, with zero interference from the others.

<Callout kind="tip" title="Why 'no interference' matters">
  If `b1` and `b2` are orthogonal, projecting a vector onto `b1` tells you nothing that overlaps
  with projecting onto `b2` — each captures a genuinely separate piece of information. This is
  exactly why orthonormal bases (like the standard x/y/z axes) feel so natural to work with:
  moving along one axis never secretly changes your position along another.
</Callout>

<h2 id="math">Projecting onto an orthonormal basis</h2>

For an *orthonormal* set `{e_1, ..., e_k}` (each unit length, all mutually perpendicular), the
projection formula from last lesson simplifies: since `e_i · e_i = 1`, the division disappears
entirely:

<MathBlock tex="\mathrm{proj}_{\vec{e}_i}(\vec{a}) = (\vec{a}\cdot\vec{e}_i)\,\vec{e}_i" />

And the projection onto the *entire subspace* spanned by `{e_1, ..., e_k}` is just the sum of
the individual projections — no cross-terms, no interaction between them:

<MathBlock tex="\mathrm{proj}_{\text{subspace}}(\vec{a}) = \sum_{i=1}^{k} (\vec{a}\cdot\vec{e}_i)\,\vec{e}_i" />

## Summary

An orthonormal set of vectors is mutually perpendicular and unit length, which makes projecting
onto the subspace they span reduce to a simple sum of independent per-direction projections —
no cross-terms, because orthogonality guarantees each direction captures information the others
can't overlap with. This "clean decomposition" property is why orthonormal bases are the
default choice whenever one is available or constructible.
