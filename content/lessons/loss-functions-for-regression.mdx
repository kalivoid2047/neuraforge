<h2 id="intuition">A single number measuring "how wrong" the network is</h2>

Gradient descent needs something to minimize — a **loss function** that turns "how wrong are
the network's predictions" into a single number. For predicting continuous values (regression),
the standard choice is **mean squared error (MSE)**: average the squared difference between
each prediction and its true target.

<h2 id="math">Mean squared error</h2>

For predictions `ŷ_i` and true targets `y_i` over `n` examples:

<MathBlock tex="\text{MSE} = \frac{1}{n}\sum_{i=1}^{n} (\hat{y}_i - y_i)^2" />

<Callout kind="tip" title="Why square the error instead of just summing it?">
  Three reasons, all important: (1) squaring makes every term non-negative, so errors in
  opposite directions can't cancel out and hide each other; (2) it's differentiable everywhere,
  unlike the absolute-value error `|ŷ-y|` which has a sharp corner at zero; (3) it penalizes
  *large* errors disproportionately more than small ones — being off by 10 costs 100x more than
  being off by 1, not just 10x, which strongly discourages any single wildly-wrong prediction.
</Callout>

The gradient of MSE with respect to one prediction `ŷ_i` (holding the target fixed, via the
power rule from week one):

<MathBlock tex="\frac{\partial \text{MSE}}{\partial \hat{y}_i} = \frac{2}{n}(\hat{y}_i - y_i)" />

## Summary

Mean squared error averages the squared difference between predictions and targets, giving a
single differentiable number that penalizes large errors disproportionately more than small
ones. Its gradient with respect to each prediction, `(2/n)(ŷ-y)`, is exactly the signal gradient
descent needs to know which direction to push each prediction — and, via the chain rule, which
direction to push every weight that produced it. The next lesson looks at how the learning rate
affects whether this process actually converges.
