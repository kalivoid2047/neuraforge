<h2 id="intuition">Week three: turning raw text into something a model can use</h2>

Every model this month expects numbers, not sentences. Before any of the probability or
information-theoretic machinery this month built can touch text, the text itself needs
converting into a structured, numeric-friendly form — starting with **tokenization**: splitting
a raw string into a list of discrete units (usually words), the first and most foundational step
of any text pipeline.

<h2 id="math">The preprocessing pipeline</h2>

A typical classical NLP pipeline runs several steps in sequence:

1. **Tokenization** — split text into individual tokens (words, punctuation)
2. **Lowercasing** — treat `"Free"` and `"free"` as the same token
3. **Stopword removal** — discard extremely common words (`"the"`, `"is"`, `"and"`) that carry
   little topic-specific signal
4. Optionally, **stemming/lemmatization** — collapse related word forms (`"running"`, `"ran"` →
   `"run"`) — not implemented here, but worth knowing exists

<Callout kind="tip" title="Lowercasing and stopword removal are trade-offs, not free wins">
  Lowercasing loses the distinction between `"Apple"` (the company) and `"apple"` (the fruit) —
  usually a reasonable trade for simplicity, but not always. Removing stopwords assumes they
  carry no useful signal, which is often true for topic classification but can be actively
  harmful for tasks where function words matter (e.g., detecting sentiment, where "not good" and
  "good" differ entirely because of a word many stopword lists would discard). Every step here
  is a modeling *choice*, not a mandatory law.
</Callout>

## Summary

A text preprocessing pipeline — tokenize, lowercase, remove stopwords — converts raw text into
a cleaned list of tokens ready for numeric representation. Each step is a deliberate modeling
choice with real trade-offs, not a mandatory law: lowercasing loses case information, and
stopword removal can destroy task-critical signal (like negation words for sentiment analysis),
verified directly above. The next lesson takes these cleaned tokens and builds the first actual
numeric representation: bag-of-words.
