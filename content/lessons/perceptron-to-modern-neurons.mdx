<h2 id="intuition">Closing week two: what actually changed since 1958</h2>

The modern artificial neuron used in every network for the rest of this course is remarkably
close to Rosenblatt's original perceptron — the same weighted sum, the same bias. Exactly two
changes separate them, and both exist to solve problems this week has already surfaced:
XOR's linear-separability wall, and (not yet covered, but coming in Month 3) how to actually
train multiple layers of neurons together.

<h2 id="math">Change 1: a smooth activation, not a hard threshold</h2>

The perceptron's step function (`1` if `z ≥ 0` else `0`) is discontinuous — it jumps instantly
from 0 to 1 with no gradient information anywhere except that single jump point (where the
gradient is technically undefined). Training multiple layers together (Month 3's
backpropagation) needs to compute *how much* changing a weight would improve the output — which
requires a smoothly varying, differentiable function, not a hard jump. This lesson doesn't
derive gradients yet (Month 3 does), but the motivating problem is worth previewing now:

<MathBlock tex="\text{perceptron: } \hat{y} = \mathrm{step}(z) \qquad \text{modern: } \hat{y} = \sigma(z) \text{ (a smooth function, e.g. sigmoid)}" />

Next week covers exactly which smooth functions (`σ`) are used in practice and why.

<h2 id="math2">Change 2: many neurons, stacked in layers</h2>

A single neuron, however its activation is chosen, is still fundamentally computing one
weighted sum — it's still limited to linear decision boundaries in the SAME sense a perceptron
is (a smooth activation doesn't by itself fix XOR). The real escape from linear separability is
**stacking neurons into layers**: a first layer of several neurons, each learning a different
linear boundary, feeding into a second layer that combines their outputs. Week four builds this
precisely; for now, the key insight to hold onto:

<Callout kind="tip" title="Why depth (not just a smoother activation) fixes XOR">
  A first-layer neuron could learn "is `x1 OR x2` true," another could learn "is `x1 AND x2`
  true" — individually still linear boundaries, each perfectly capable on their own. A
  second-layer neuron can then combine those two outputs (`OR` minus `AND`, informally) to
  reconstruct XOR — the *combination* of two linear boundaries is what a single linear boundary
  could never express alone.
</Callout>

<h2 id="python">Previewing the shape of the solution (weights hand-set, not yet learned)</h2>

<Callout kind="tip" title="Hand-set today, learned starting Month 3">
  Every weight above was chosen by hand, exactly like the AND/OR gates from two lessons ago —
  the point here is purely to demonstrate that a two-layer network *can* represent XOR, escaping
  the single-perceptron wall. Learning these weights automatically from data, for networks far
  too large to hand-design, is exactly what backpropagation (Month 3) provides.
</Callout>

## Summary

Two changes separate the 1958 perceptron from a modern artificial neuron: a smooth,
differentiable activation function (enabling gradient-based training, Month 3) and stacking
multiple neurons into layers (escaping the linear-separability limit XOR exposed). Neither
change alone is sufficient — smoothness fixes trainability, depth fixes representational
capacity — but together they're the foundation of every network built for the rest of this
course.
