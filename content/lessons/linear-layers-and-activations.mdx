<h2 id="intuition">The two building blocks of almost every network</h2>

`nn.Linear` computes exactly the `y = xW + b` operation from two lessons ago — one call
replacing the manual matrix multiply and bias add. An **activation function** applied right
after it introduces the nonlinearity that Month 3's `capstone-backprop-engine` lesson showed is
*required* for a network to represent anything beyond a straight line (recall: stacked linear
operations, with no nonlinearity between them, always collapse into a single linear operation).
`nn.ReLU`, `nn.Tanh`, and `nn.Sigmoid` are PyTorch's pre-built activation modules — the
`torch.tanh` used throughout Month 3, now packaged as a layer you can drop into a network
alongside `nn.Linear`.

<h2 id="math">Linear layer, then activation</h2>

<MathBlock tex="y = xW + b \qquad a = \text{activation}(y)" />

Three common activation choices and their formulas:

<MathBlock tex="\text{ReLU}(y) = \max(0, y) \qquad \tanh(y) = \frac{e^{y}-e^{-y}}{e^{y}+e^{-y}} \qquad \sigma(y) = \frac{1}{1+e^{-y}}" />

```python
# reference only -- torch isn't available in this browser sandbox
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(3, 4),
    nn.ReLU(),
    nn.Linear(4, 1),
)
# nn.Sequential just chains forward() calls: linear -> relu -> linear, in order
```

<Callout kind="tip" title="Why ReLU won out over tanh/sigmoid for hidden layers">
  Both `tanh` and `sigmoid` **saturate** — for large positive or negative inputs, their output
  flattens out and their derivative shrinks toward zero (recall `tanh`'s derivative,
  `1 - tanh(x)²`, which is nearly `0` once `|x|` is large). Stack many such layers, and
  gradients shrink multiplicatively at every layer on the way back (the "vanishing gradient"
  problem). `ReLU`'s derivative is exactly `1` for any positive input, no matter how large — it
  doesn't saturate on that side, which is a major practical reason it became the default choice
  for hidden layers in deep networks.
</Callout>

## Summary

`nn.Linear` implements the `y = xW + b` operation verified two lessons ago; activation functions
(`ReLU`, `tanh`, `sigmoid`) introduce the nonlinearity a network needs to represent anything
beyond a straight line, exactly as Month 3's XOR capstone demonstrated. `nn.Sequential` is just
syntactic convenience for chaining layers in order — verified above with a plain Python
function doing the identical chaining. ReLU's non-saturating derivative for positive inputs is
a major practical reason it's the default choice for hidden layers in deep networks. The next
lesson covers loss functions beyond MSE — specifically cross-entropy, needed for classification
tasks like this month's capstone.
