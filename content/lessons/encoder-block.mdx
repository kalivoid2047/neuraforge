<h2 id="intuition">Every piece so far, assembled</h2>

You've now built every individual piece: multi-head attention, positional encoding, LayerNorm,
residual connections, and the feed-forward network. An encoder block is simply these pieces
combined in a specific, fixed pattern — and a full encoder is `N` of these blocks stacked.
Nothing new to learn conceptually here; this lesson is about **assembly and shape discipline**.

<h2 id="math">The full block (pre-norm)</h2>

<MathBlock tex="x_1 = x + \mathrm{MultiHeadAttention}(\mathrm{LayerNorm}(x))" />
<MathBlock tex="x_2 = x_1 + \mathrm{FFN}(\mathrm{LayerNorm}(x_1))" />

Two sublayers, each wrapped in the same pattern: normalize, transform, add back the residual.
Critically, the block's **output shape exactly matches its input shape** — `(seq_len, d_model)`
in, `(seq_len, d_model)` out. This is what makes stacking `N` blocks trivial: block 2's input is
just block 1's output, no shape-adapter needed anywhere.

<h2 id="python">A complete, stackable encoder block</h2>

(h, seq_len, d_k)\n    out = out.transpose(1, 0, 2).reshape(seq_len, d_model)\n    return out @ Wo\n\ndef feed_forward(x, W1, b1, W2, b2):\n    return (np.maximum(0, x @ W1 + b1)) @ W2 + b2\n\nclass EncoderBlock:\n    def __init__(self, d_model, h, d_ff, seed):\n        rng = np.random.RandomState(seed)\n        s = 0.1\n        self.Wq = rng.randn(d_model, d_model) * s\n        self.Wk = rng.randn(d_model, d_model) * s\n        self.Wv = rng.randn(d_model, d_model) * s\n        self.Wo = rng.randn(d_model, d_model) * s\n        self.W1 = rng.randn(d_model, d_ff) * s\n        self.b1 = np.zeros(d_ff)\n        self.W2 = rng.randn(d_ff, d_model) * s\n        self.b2 = np.zeros(d_model)\n        self.h = h\n\n    def forward(self, x):\n        attn_out = multi_head_attention(layer_norm(x), self.Wq, self.Wk, self.Wv, self.Wo, self.h)\n        x = x + attn_out\n        ffn_out = feed_forward(layer_norm(x), self.W1, self.b1, self.W2, self.b2)\n        x = x + ffn_out\n        return x\n\n# Stack 6 encoder blocks and trace shape through every one\nseq_len, d_model, h, d_ff, n_layers = 10, 64, 8, 256, 6\nx = np.random.RandomState(0).randn(seq_len, d_model)\n\nblocks = [EncoderBlock(d_model, h, d_ff, seed=i) for i in range(n_layers)]\nfor i, block in enumerate(blocks):\n    x = block.forward(x)\n    assert x.shape == (seq_len, d_model), f\"shape broke at layer {i}\"\n\nprint(f\"shape preserved across all {n_layers} layers: {x.shape}\")\nprint(\"no NaNs after 6 layers:\", not np.isnan(x).any())"}

<Callout kind="tip" title="Debugging habit worth keeping">
  That `assert x.shape == (seq_len, d_model)` inside the loop is cheap insurance. Shape bugs in
  deep stacks are otherwise brutal to localize — they surface as an error many layers away from
  where the mismatch actually originated.
</Callout>

## Summary

An encoder block is multi-head attention and a feed-forward network, each wrapped in
pre-norm-then-residual-add. Because every residual connection requires the sublayer's output
shape to match its input shape, the whole block preserves `(seq_len, d_model)` end to end —
which is exactly what makes stacking `N` identical blocks straightforward, with no shape
adapters needed anywhere in between.
