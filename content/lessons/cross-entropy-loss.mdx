<h2 id="intuition">MSE measures distance; classification needs to measure confidence</h2>

Month 3's MSE loss fits naturally when predicting a continuous number. This month's capstone is
an **image classifier** — predicting *which* of several discrete categories an image belongs
to, not a continuous value. That needs a different loss: **cross-entropy**, which measures how
confidently and correctly a network's predicted probability distribution matches the true
category, rather than the distance between two numbers.

<h2 id="math">Softmax and cross-entropy</h2>

A classification network's raw output (before any probability conversion) is called **logits**
— one real number per class, with no constraint that they sum to anything meaningful.
**Softmax** converts logits into a genuine probability distribution:

<MathBlock tex="\text{softmax}(z)_i = \frac{e^{z_i}}{\sum_{j} e^{z_j}}" />

Every output is positive and the whole vector sums to `1` — a valid probability distribution.
**Cross-entropy loss** then measures how much probability the network assigned to the *correct*
class:

<MathBlock tex="L = -\log(\hat{p}_{\text{correct class}})" />

<Callout kind="tip" title="Why the negative log, and not just 1 - probability?">
  The negative log grows **very** large as the assigned probability for the correct class
  approaches `0` — the loss punishes confident *wrong* predictions severely, while `1 - p` would
  only ever range over `[0, 1]`, punishing them only mildly. This makes cross-entropy a much
  sharper training signal: predicting the correct class with 1% confidence is treated as a much
  bigger mistake than predicting it with 40% confidence, even though both are "wrong" in the
  sense of not being the top prediction.
</Callout>

## Summary

Softmax converts raw logits into a valid probability distribution; cross-entropy loss,
`-log(p_correct)`, measures how much probability that distribution assigns to the true class,
punishing confident wrong predictions far more sharply than a plain `1-p` measure would. Its
gradient with respect to the logits has an elegantly simple closed form,
`softmax(logits) - one_hot(true_class)`, verified numerically above. This is the loss function
this month's Image Classifier capstone will actually use. The next lesson covers the optimizers
(SGD and Adam) that turn any loss's gradient into an actual parameter update.
