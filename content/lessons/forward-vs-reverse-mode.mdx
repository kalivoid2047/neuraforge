<h2 id="intuition">Closing week two: why backprop walks the graph backward</h2>

A computational graph can be traversed in two directions to compute derivatives, and the choice
has enormous practical consequences. This lesson explains both directions and why neural
network training exclusively uses one of them.

<h2 id="math">Two ways to walk the graph</h2>

**Forward mode**: alongside each node's *value*, also carry its derivative with respect to one
chosen input, computed left-to-right (in the same order as the forward pass). One forward-mode
pass gives you `∂(every output)/∂(one input)` — the derivative of everything with respect to a
single input variable.

**Reverse mode**: first run the forward pass to get all values, then walk the graph
*backward* from the output, accumulating `∂(one output)/∂(every node)` using the chain rule at
each step. One reverse-mode pass gives you `∂(one output)/∂(every input)` — the derivative of a
single output with respect to everything.

<Callout kind="tip" title="The asymmetry that decides everything">
  A neural network has **millions of inputs** (the weights) and typically **one output** (the
  scalar loss). Forward mode would need one full pass *per weight* to get the full gradient —
  millions of passes. Reverse mode needs exactly **one** pass, regardless of how many weights
  there are, because it computes the derivative of the one output with respect to everything
  simultaneously. This is precisely why backpropagation — reverse-mode automatic
  differentiation — is the only viable choice for training networks with millions or billions
  of parameters.
</Callout>

## Summary

Forward-mode differentiation computes one input's effect on every output in a single pass;
reverse-mode computes every input's effect on one output in a single pass. Because neural
networks have millions of weights (inputs) and one scalar loss (output), reverse mode's cost —
independent of input count — is the only practical choice, which is exactly what backpropagation
is: reverse-mode automatic differentiation over a computational graph. Week three builds a real
autograd engine that implements this.
