<h2 id="intuition">Naming the gap from last lesson</h2>

Last lesson showed cross-entropy `H(P,Q)` always exceeds `H(P)` unless `Q` matches `P` exactly —
that gap itself is useful enough to deserve its own name: **KL divergence**,
`D_{KL}(P \| Q)`. It measures specifically how much *worse* `Q` is as a stand-in for `P`, with
the entropy-vs-cross-entropy relationship built directly into its definition.

<h2 id="math">Isolating the extra cost</h2>

<MathBlock tex="D_{KL}(P \| Q) = H(P,Q) - H(P) = \sum_i P(i)\log_2\frac{P(i)}{Q(i)}" />

Because `H(P,Q) \geq H(P)` always (Gibbs' inequality, last lesson), `D_{KL}(P\|Q) \geq 0`
always, with equality exactly when `Q=P` everywhere.

<Callout kind="tip" title="Why KL divergence is NOT a real 'distance'">
  A true distance metric must be symmetric (`d(x,y)=d(y,x)`) — but
  `D_{KL}(P\|Q) \neq D_{KL}(Q\|P)` in general. Concretely: `D_{KL}(P\|Q)` heavily penalizes `Q`
  assigning near-zero probability to something `P` considers likely (that log ratio blows up),
  while `D_{KL}(Q\|P)` penalizes the reverse situation instead. This asymmetry is genuinely
  useful — which direction you use depends on what kind of mismatch you care about most — but it
  does mean "KL distance" is a loose, technically-incorrect nickname worth knowing is imprecise.
</Callout>

## Summary

KL divergence, `D_KL(P‖Q) = H(P,Q) - H(P)`, isolates exactly the "extra cost" of using `Q` in
place of `P` — always non-negative, zero exactly when the distributions match, but genuinely
asymmetric (`D_KL(P‖Q) ≠ D_KL(Q‖P)` in general), both properties verified directly above. This
asymmetry disqualifies it as a true distance metric despite measuring real dissimilarity. The
next lesson returns to softmax — not as an ad hoc formula, but as the specific function that
arises naturally from these information-theoretic ideas.
