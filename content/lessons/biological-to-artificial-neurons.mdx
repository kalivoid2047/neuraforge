<h2 id="intuition">Week two: from linear algebra to the first "neural" model</h2>

Everything in week one — eigenvectors, projections, norms — was preparation. This week
introduces the **perceptron**, the earliest artificial neuron model and the direct ancestor of
every neural network you'll build for the rest of this course. It's named for a loose analogy
to biological neurons, worth understanding both for the intuition it provides and for where it
genuinely stops applying.

<h2 id="history">A brief, honest history</h2>

<Callout kind="history" title="McCulloch & Pitts (1943), then Rosenblatt (1958)">
  A biological neuron receives electrical/chemical signals from many other neurons through
  connections called synapses, each with a different "strength." If the combined incoming
  signal exceeds some threshold, the neuron "fires," sending its own signal onward. McCulloch
  and Pitts formalized a simplified mathematical version of this in 1943; Frank Rosenblatt built
  it into a trainable model — the perceptron — in 1958, complete with a learning algorithm
  (next lesson) and, notably, actual hardware built to run it.
</Callout>

<Callout kind="warning" title="Where the biological analogy breaks down">
  Real neurons are vastly more complex than this model suggests: they communicate with discrete
  electrical spikes (not smooth continuous values), operate on timescales and with chemical
  mechanisms the artificial model ignores entirely, and a real brain's learning process bears
  only a loose resemblance to gradient-based training (Month 3). Treat "artificial neuron" as a
  useful *name* and a starting *intuition*, not a claim that this model faithfully simulates
  biology — it doesn't, and modern deep learning research has largely moved past the biological
  framing as a source of new ideas.
</Callout>

<h2 id="structure">The three-part structure, informally</h2>

Every artificial neuron, from the 1958 perceptron to a modern Transformer's attention head,
shares this shape:

1. **Inputs** — some numbers coming in (from data, or from other neurons).
2. **Weights** — one learned number per input, controlling how much that input matters.
3. **Activation** — combine inputs and weights into one number, then apply a decision rule.

The next four lessons build exactly this, precisely: how the inputs and weights combine (the
perceptron model), how the weights get learned from data (the learning algorithm), what the
model can and can't represent (linear separability), and how this simple structure connects
forward to every modern architecture.

## Summary

The artificial neuron takes loose inspiration from biological neurons — weighted incoming
signals, a threshold-based decision — formalized by McCulloch and Pitts (1943) and made
trainable by Rosenblatt's perceptron (1958). The biological analogy is useful for intuition but
breaks down under scrutiny; every artificial neuron since shares the same three-part structure
(inputs, weights, activation), which the rest of this week builds precisely.
