<h2 id="intuition">When one input feeds into several intermediate quantities</h2>

Real networks aren't a simple straight-line chain — an input often feeds into *multiple*
intermediate quantities, which then combine to produce the output. Picture `z = f(x, y)` where
both `x` and `y` themselves depend on some shared variable `t`. Changing `t` affects `z`
through **two separate paths**: one through `x`, one through `y`. The multivariable chain rule
says: **sum the contribution from every path.**

<h2 id="math">The multivariable chain rule</h2>

For `z = f(x, y)` where `x = x(t)` and `y = y(t)`:

<MathBlock tex="\frac{dz}{dt} = \frac{\partial f}{\partial x}\cdot\frac{dx}{dt} + \frac{\partial f}{\partial y}\cdot\frac{dy}{dt}" />

Each term is a path from `t` to `z`: one path goes `t → x → z`, contributing
`(∂f/∂x)·(dx/dt)`; the other goes `t → y → z`, contributing `(∂f/∂y)·(dy/dt)`. Add them, because
both paths' effects happen simultaneously and both contribute to the total change in `z`.

<Callout kind="tip" title="This 'sum over paths' idea is the whole ballgame">
  In a neural network, a single weight in an early layer can influence the final loss through
  many different downstream paths (through different neurons in later layers). The multivariable
  chain rule is precisely the rule that says: to get the total effect of that one weight on the
  loss, sum its contribution along *every* path from that weight to the output. Backpropagation
  (week three) is an efficient algorithm for computing exactly this sum, for every weight at
  once, without literally enumerating every path.
</Callout>

## Summary

The multivariable chain rule generalizes the chain rule to inputs that influence an output
through multiple intermediate variables: sum the path-by-path contributions, each one a product
of a partial derivative and an intermediate derivative. This "sum over paths" structure is
exactly what a computational graph (two lessons ahead) makes explicit, and exactly what
backpropagation computes efficiently for every weight in a network simultaneously.
