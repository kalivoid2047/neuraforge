<h2 id="intuition">Two unglamorous ideas that make deep networks actually trainable</h2>

Attention and feed-forward layers get all the conceptual attention (pun intended), but stack a
dozen of them without two supporting mechanisms and the network simply won't train: **residual
connections** (let gradients skip straight through a layer) and **layer normalization**
(keep activation statistics stable as they flow through dozens of layers).

<Callout kind="tip" title="Residual connections, in one line">
  Instead of `output = Layer(x)`, every Transformer sublayer computes `output = x + Layer(x)` —
  the input is always added back. If `Layer(x)` learns to output near-zero, the block reduces
  to the identity function, which is trivially easy to learn and gives gradients a direct path
  back to earlier layers.
</Callout>

<h2 id="math">LayerNorm, precisely</h2>

Unlike batch normalization (which normalizes across the batch dimension), layer normalization
normalizes across the **feature dimension**, independently for every single token:

<MathBlock tex="\mathrm{LayerNorm}(x) = \gamma\cdot\frac{x-\mu}{\sqrt{\sigma^2+\epsilon}}+\beta, \qquad \mu=\frac{1}{d}\sum_i x_i,\quad \sigma^2=\frac{1}{d}\sum_i (x_i-\mu)^2" />

`γ` and `β` are learned per-dimension scale and shift parameters — LayerNorm forces zero mean,
unit variance *before* applying them, then lets the network learn to rescale if that's useful.
`ε` is a small constant purely to avoid division by zero.

A full Transformer sublayer combines both ideas:

<MathBlock tex="x_{\text{out}} = x + \mathrm{Sublayer}(\mathrm{LayerNorm}(x)) \qquad \text{(pre-norm, used by GPT-2 onward)}" />

<Callout kind="warning" title="Pre-norm vs. post-norm">
  The original Transformer paper placed LayerNorm *after* the residual add (post-norm):
  `x + Sublayer(x)`, then normalize. This works for shallow stacks but becomes unstable to train
  as depth grows past ~12 layers without careful learning-rate warmup. Placing LayerNorm
  *before* the sublayer instead (pre-norm) — normalizing the input the sublayer sees, while the
  residual path stays completely unnormalized — trains far more stably at depth, which is why
  GPT-2 onward, and essentially every modern large model, uses pre-norm.
</Callout>

## Summary

Residual connections (`x + Sublayer(x)`) let gradients and information bypass a sublayer
entirely if needed, making very deep stacks trainable. Layer normalization rescales each
token's features to zero mean and unit variance independently, keeping activation statistics
stable across dozens of layers. Modern models place LayerNorm *before* each sublayer (pre-norm)
rather than after, for training stability at depth.
