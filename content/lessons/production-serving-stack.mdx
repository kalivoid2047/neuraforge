<h2 id="intuition">Month 12: making it survive contact with real traffic</h2>

Eleven months produced things that work when you run them. This month is about the difference between working and *staying* working — under load, on a machine you do not babysit, while you deploy changes to it. It starts with the stack that actually serves requests.

<h2 id="math">Four Layers, Four Jobs</h2>

Four layers, each owning something the others must not:

<table>
<thead><tr><th>layer</th><th>what it is</th><th>what it owns</th></tr></thead>
<tbody>
<tr><td>nginx</td><td>reverse proxy</td><td>TLS, static files, rate limits, buffering</td></tr>
<tr><td>gunicorn</td><td>process manager</td><td>N workers, restarts, graceful reload</td></tr>
<tr><td>uvicorn</td><td>ASGI worker</td><td>the event loop inside each worker</td></tr>
<tr><td>FastAPI</td><td>the application</td><td>your routes</td></tr>
</tbody>
</table>

Processes give **parallelism** across cores, since the GIL is per-process, plus fault isolation — one worker segfaulting does not take the service down. The event loop inside each gives **concurrency** across I/O waits. Neither substitutes for the other.

<Callout kind="tip" title="Binding to loopback is a security control">
  The real unit file runs `--bind 127.0.0.1:8001`. That single flag means the application is unreachable from the network **except** through nginx, so every header, body limit and TLS setting configured at the proxy is unbypassable. Binding `0.0.0.0` here — a one-character change that makes local testing marginally easier — exposes the API directly and silently voids all of it.
</Callout>

<Callout kind="warning" title="A model, not a benchmark">
  There is no GPU or web server in this browser, so the numbers below come from an explicit
  cost *model* — stated constants for service time, throughput and price — not from a
  measurement of real hardware. That is the honest framing, and it is also how capacity planning
  is actually done before the hardware is bought. What the cell demonstrates is the **shape** of
  the trade: which way each curve bends, and where it goes vertical. Substitute your own measured
  constants and the conclusions follow the same shape.
</Callout>

## Summary

The serving stack is nginx, gunicorn, uvicorn, FastAPI — proxy, process manager, event loop, application. Processes buy parallelism across cores and fault isolation; the event loop buys concurrency across I/O waits; production needs both. And binding to `127.0.0.1` makes the proxy unbypassable, which is why that flag is a security control rather than a detail. The next lesson asks how many workers you actually need.
