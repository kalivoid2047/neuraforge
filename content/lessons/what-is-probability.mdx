<h2 id="intuition">Month 5: the mathematics of uncertainty</h2>

Every month so far has assumed the data was simply given. Real machine learning constantly
reasons about uncertainty: how confident is this prediction, how surprised should the model be
by this outcome, how do we compare two predicted distributions? **Probability theory** is the
mathematical language for all of that — and by the end of this month, it directly explains
*why* cross-entropy (Month 4's loss function) has the exact form it does, and builds toward a
working text classifier.

<h2 id="math">Sample spaces, events, and the axioms</h2>

The **sample space** `Ω` is the set of all possible outcomes of some random process (e.g., for
one die roll, `Ω = {1,2,3,4,5,6}`). An **event** is any subset of the sample space (e.g., "rolled
an even number" = `{2,4,6}`). A valid probability assignment `P` must satisfy three axioms:

<MathBlock tex="P(E) \geq 0 \ \text{for every event } E \qquad P(\Omega) = 1 \qquad P(E_1 \cup E_2) = P(E_1) + P(E_2) \ \text{if } E_1 \cap E_2 = \emptyset" />

In words: probabilities are never negative, the probability that *something* in the sample
space happens is exactly `1`, and the probability of either of two *mutually exclusive* events
happening is just the sum of their individual probabilities. Every other probability rule used
this month is derived from these three facts.

<Callout kind="tip" title="Probability as long-run relative frequency">
  For a fair die, `P(\{2,4,6\}) = 3/6 = 0.5` isn't just a definition — it's a claim about what
  happens if you actually rolled the die many, many times: the *fraction* of rolls landing on an
  even number should approach `0.5` as the number of rolls grows. This "long-run frequency"
  interpretation is exactly what the code below verifies directly, by simulation.
</Callout>

<h2 id="python">Verifying a theoretical probability against simulation</h2>

<CodeCell
  code={"import numpy as np\n\nrng = np.random.default_rng(0)\n\n# sample space for one die roll: {1,2,3,4,5,6}, each equally likely\n# event: rolling an even number -> {2,4,6}\ntheoretical_prob = 3 / 6\n\nfor n_rolls in [10, 100, 1000, 100_000, 1_000_000]:\n    rolls = rng.integers(1, 7, size=n_rolls)   # simulate n_rolls fair die rolls\n    is_even = (rolls % 2 == 0)\n    empirical_prob = is_even.mean()\n    print(f\"n_rolls={n_rolls:>8}: empirical P(even) = {empirical_prob:.4f}  (theoretical = {theoretical_prob:.4f})\")\n\nprint()\n\n# verify the axioms directly on simulated data\nn = 1_000_000\nrolls = rng.integers(1, 7, size=n)\np_all_outcomes = sum((rolls == k).mean() for k in range(1, 7))\nprint(f\"sum of P(k) for k=1..6 (should be 1.0, the P(omega)=1 axiom): {p_all_outcomes:.4f}\")\n\np_even = (rolls % 2 == 0).mean()\np_2 = (rolls == 2).mean()\np_4 = (rolls == 4).mean()\np_6 = (rolls == 6).mean()\nprint(f\"P(even) = {p_even:.4f}  vs  P(2)+P(4)+P(6) = {p_2+p_4+p_6:.4f}  (mutually exclusive events, additivity axiom)\")"}

## Summary

A sample space enumerates every possible outcome; an event is a subset of it; and every valid
probability assignment satisfies three axioms — non-negativity, `P(Ω)=1`, and additivity over
mutually exclusive events. Simulation confirms the "long-run relative frequency" interpretation
directly: as the number of trials grows, empirical frequencies converge to the theoretical
probability, and the axioms hold exactly on simulated data. The next lesson covers conditional
probability — how learning that one event occurred changes the probability of another.
